# MergFS-Efficient-Bridging-of-a-32-bit-High-Speed-ICB-Bus-to-a-64-bit-Low-Speed-AHB-Lite-Bus-
Designed and verified MergFS, a request-merging ICB-to-AHB-Lite bus bridge for RISC-V SoCs, achieving up to 75% clock-cycle reduction over a non-merging baseline through 32-bit-to-64-bit request merging and frequency-aware buffering. Built a complete SystemVerilog class-based verification environment in Cadence Xcelium validating its functionality.
ICB-MergFS is a hardware bus bridge that connects a 32-bit high-speed Intra-Core Bus (ICB) used in the Hummingbird E203 RISC-V processor, to a 64-bit lower-speed AHB-Lite system bus. A naive bridge converts each 32-bit ICB transaction into its own AHB-Lite transfer, leaving half the 64-bit bus bandwidth unused and breaking AHB's pipelined address/data overlap, which together can double or quadruple the effective transfer latency. ICB-MergFS addresses both problems: an ICB Merge Unit detects pairs of adjacent, address-aligned 32-bit requests and merges them into a single 64-bit AHB-Lite transaction, fully utilizing the bus width, while a frequency-aware FIFO preserves AHB-Lite pipelining across the ICB-to-AHB clock-domain boundary. The design supports configurable ICB-to-AHB-Lite clock ratios and was verified with a complete SystemVerilog class-based testbench and a suite of SystemVerilog Assertions covering protocol correctness, FIFO safety, and response ordering against directed and constrained-random test cases in Cadence Xcelium.
